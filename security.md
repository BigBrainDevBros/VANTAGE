# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| Current GitHub Pages build and `main` | Yes |
| Earlier builds | No |

## Reporting A Vulnerability

Send a private report to the maintainers with the affected build, browser, reproduction steps, and impact. Use GitHub's private reporting option if it is available for VANTAGE. Otherwise, email the organisation contact at evengao6688@gmail.com. Keep vulnerability details out of public issues.

[Private Vulnerability Report](https://github.com/BigBrainDevBros/VANTAGE/security/advisories/new)
