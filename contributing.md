# Contributing To VANTAGE

[简体中文](contributing.zh-cn.md) · [Project Guide](readme.md)

This repository distributes the playable build. The author maintains the editable game sources separately. For a gameplay change, discuss the intended behavior with the maintainer before modifying the distribution.

For a documentation change, update the corresponding English and Chinese guides. Preserve the author credits and third-party notices. Run `python3 scripts/check-repository.py` from the repository root. Use a lowercase commit type followed by three lowercase words.

For a report about a game build, include the map, browser, settings and steps that reproduced the problem. Distinguish a solo session from a room with two players. Document observed results in the pull request. [Report A Bug](https://github.com/BigBrainDevBros/VANTAGE/issues/new?template=bug_report.md)
